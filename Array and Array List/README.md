# Array and Array List

This assignment demonstrates the use of **arrays and ArrayList** in Java through a simple bank account simulation.

## Structure

| File | Description |
| --- | --- |
| `Akun.java` | Account model. Stores name, balance, password, and transaction count. Uses a static `ArrayList<Akun>` as the account store. |
| `Bank.java` | Bank application with a Swing GUI. Handles registration, login, deposit, and withdrawal. |

## Features

- Register a new account
- Login with name and password
- Deposit and withdraw money
- Display balance and number of transactions

## Usage

Compile and run the GUI application:

```bash
javac *.java
java Bank
```
