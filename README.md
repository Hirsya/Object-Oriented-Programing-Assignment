# Object-Oriented-Programming-Assignment

This repository contains my assignments for the **Object-Oriented Programming** course (OOP).

Each assignment focuses on applying core OOP concepts in Java, such as encapsulation, inheritance, polymorphism, the use of collections like arrays and ArrayLists, and building desktop interfaces with Java Swing.

## Structure

Assignments are organized by topic. See each folder's README for details.

- [`Array and Array List`](./Array%20and%20Array%20List) — Bank account simulation using arrays and ArrayList.
- [`Inheritance and Polymorphism`](./Inheritance%20and%20Polymorphism) — Geometric shapes demonstrating inheritance and polymorphism.
- [`GUI Project`](./GUI%20Project) — *Astral Messenger*, a Java Swing chat UI built from the standard component hierarchy.
